# Blazor Scheduler Row Auto Height

A quick-start project that helps you how to implement Row Auto Height in Blazor Scheduler Component. 

## Repository Description

This sample demonstrates how to automatically adjust row heights based on content in Syncfusion Blazor Scheduler component, improving the visual presentation and user experience when displaying events with varying content lengths.

## Features

- Automatic row height adjustment based on content
- Adaptive layout for different event types
- Seamless integration with Blazor Scheduler
- Responsive design for multiple device types

## Project Prerequisites

Make sure that you have the latest versions of Visual Studio 2022 installed on your machine before starting to work on this project.

## How to Run This Application

1. Clone the <code>blazor-scheduler-row-auto-height</code> repository and open it in Visual Studio 2022.

2. Register the Syncfusion license key in the Program.cs file. For guidance, refer to the documentation: https://blazor.syncfusion.com/documentation/getting-started/license-key/how-to-register-in-an-application

3. Build and run your project to view the output.
